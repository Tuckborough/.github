# Tuckborough

**Tuckborough** is the software engineering organization powering **Cleva** (formerly *"L'Adjoint"*), the next-generation AI CRM and workflow assistant specialized for real estate brokers in Québec.

---

## 🏛️ Project Architecture & Repositories

- **[`cleva-docs`](https://github.com/Tuckborough/cleva-docs)**: Product specifications, business plan, LaTeX dossiers, brand guidelines, and UI definitions.
- **[`cleva-backend`](https://github.com/Tuckborough/cleva-backend)**: Server logic, database schemas, and sovereign LLM token inference gateway.
- **[`cleva-web`](https://github.com/Tuckborough/cleva-web)**: Desktop Web application for brokers.
- **[`cleva-ios`](https://github.com/Tuckborough/cleva-ios)**: Native iOS mobile application.
- **[`cleva-android`](https://github.com/Tuckborough/cleva-android)**: Native Android mobile application.
- **[`cleva-devops`](https://github.com/Tuckborough/cleva-devops)**: Centralized DevSecOps pipelines, automated compliance scanners, and cloud deployment templates.
- **[`.github`](https://github.com/Tuckborough/.github)**: Organization-wide issue forms, pull request templates, and governance standards.

## 🔒 Governance & DevSecOps
All repositories enforce automated shift-left security (Semgrep SAST, Gitleaks, Trivy SCA) and strict compliance with Québec Law 25 personal data privacy standards.
